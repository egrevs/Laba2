### Описание проекта

Проект представляет собой учебную симуляцию боя Pokémon на Java с использованием объектно‑ориентированного подхода.
Реализованы собственные покемоны (например, Absol, линейка Tepig/Pignite/Emboar, Kabuto/Kabutops) и наборы атак разных
типов (физические, специальные, статусные). Программа демонстрирует наследование от базовых классов библиотеки,
переопределение методов и композицию через набор приёмов, с пошаговым выводом хода боя в консоль.

### Сторонняя библиотека

В проект добавлена сторонняя библиотека (модуль) Pokémon, подключённая как JAR‑файл `lib/Pokemon.jar` и используемая в
качестве основы для классов покемонов и их атак.
